# Event-Management-Systems-SQL-Portfolio-Project-
Welcome to my Event Management System built in SQL Server! This project demonstrates practical relational database design and modern analytics using SQL queries.

Features:Robust tables for users, events & registrations (with primary/foreign keys)Realistic sample data and full CRUD functionalitySQL queries for event/user analysis, ratings, revenue, leaderboardsExample Insights:Which events are most popular?Who are the most active users?What is earning potential by category?What do users say about each event?Explore the code, scripts, and screenshots to see actionable analytics in action!

## question covered:
--Q1. Analyze event popularity (total registrations--
SELECT e.event_name, COUNT(r.registration_id) AS total_registrations
FROM Events e
LEFT JOIN Registrations r ON e.event_id = r.event_id
GROUP BY e.event_name
ORDER BY total_registrations DESC;


--Q2. Average feedback for each event--
SELECT e.event_name, AVG(r.feedback_rating) AS avg_rating
FROM Events e
JOIN Registrations r ON e.event_id = r.event_id
WHERE r.feedback_rating IS NOT NULL
GROUP BY e.event_name;


--Q3.Find events with average rating > 8--
SELECT e.event_name
FROM Events e
JOIN Registrations r ON e.event_id = r.event_id
GROUP BY e.event_name
HAVING AVG(r.feedback_rating) > 8;


--Q4. Total revenue generated by each event--
SELECT e.event_name,
       e.ticket_price * COUNT(r.registration_id) AS total_revenue
FROM Events e
JOIN Registrations r ON e.event_id = r.event_id
GROUP BY e.event_name, e.ticket_price;


--Q5. Top-performing events in each category (highest avg rating)--
SELECT category, event_name, avg_rating
FROM (
    SELECT e.category, e.event_name,
           AVG(r.feedback_rating) AS avg_rating,
           RANK() OVER (PARTITION BY e.category ORDER BY AVG(r.feedback_rating) DESC) AS rnk
    FROM Events e
    JOIN Registrations r ON e.event_id = r.event_id
    GROUP BY e.category, e.event_name
) t
WHERE rnk = 1;


--Q6. Display users who attended more than one event--
SELECT u.name, COUNT(r.event_id) AS attended_events
FROM Users u
JOIN Registrations r ON u.user_id = r.user_id
WHERE r.attended = TRUE
GROUP BY u.name
HAVING COUNT(r.event_id) > 1;


--Q7.  Users who have NOT attended any event--
SELECT u.name
FROM Users u
LEFT JOIN Registrations r ON u.user_id = r.user_id AND r.attended = TRUE
GROUP BY u.user_id, u.name
HAVING COUNT(r.registration_id) = 0;


--Q8. Retrieve users who attended the MOST expensive events--

SELECT u.name, e.event_name, e.ticket_price
FROM Users u
JOIN Registrations r ON u.user_id = r.user_id
JOIN Events e ON r.event_id = e.event_id
WHERE e.ticket_price = (SELECT MAX(ticket_price) FROM Events)
  AND r.attended = TRUE;


--Q9. Leaderboard: Total events attended + average rating--
SELECT 
    u.name,
    COUNT(r.event_id) AS total_events_attended,
    AVG(r.feedback_rating) AS avg_rating
FROM Users u
JOIN Registrations r ON u.user_id = r.user_id
WHERE r.attended = TRUE
GROUP BY u.name
ORDER BY total_events_attended DESC, avg_rating DESC;
